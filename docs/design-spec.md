# 设计规范

## 色彩方案

| 用途 | 色值 | 说明 |
|------|------|------|
| 背景色 | `#0a0a0a` | 深黑底色 |
| 荧光绿 | `#00ff41` | 主要文字、玩家角色、终端文字 |
| 故障橙 | `#ff6b35` | AI 角色、警告提示、艾莉受损状态 |
| Canvas 背景-关卡1 | `#0a0a1a` | 深蓝黑（防火墙主题） |
| Canvas 背景-关卡2 | `#0f0a1a` | 深紫黑（内存主题） |
| 障碍物 | `#2a2a3a` | 深灰蓝（数据块） |
| 终点区 | `rgba(0,255,65,0.15)` | 半透明荧光绿 |
| UI 面板背景 | `rgba(0,0,0,0.8)` | 半透明黑色 |

## 字体规范

| 元素 | 字体 | 大小 | 颜色 |
|------|------|------|------|
| 计时器 | 'Courier New', monospace | 16px | #00ff41 |
| 艾莉状态 | 'Courier New', monospace | 16px | #00ff41 |
| 系统日志 | 'Consolas', 'Courier New', monospace | 13px | #00ff41 |
| Canvas 标签 | 'Courier New', monospace | 11px | #cccccc |

## UI 布局

```
┌──────────────────────────────────────┐
│ [#timer]          [#ally-status]     │  ← UI 覆盖层
│                                      │
│         ┌──────────────┐             │
│         │              │             │
│         │   Canvas     │             │
│         │   800 × 600  │             │
│         │              │             │
│         └──────────────┘             │
│                                      │
│ [#event-log 系统日志区域]            │  ← 可滚动
└──────────────────────────────────────┘
```

- 页面总宽度：840px（Canvas 800 + 边框 40）
- Canvas 边框：2px solid #00ff41，带 box-shadow 发光
- 日志区高度：120px，overflow-y: auto

## 动画效果

- **扫描线**：Canvas 上方半透明条纹伪影（::before 伪元素，repeating-linear-gradient）
- **故障闪烁**：`@keyframes blink-red`，艾莉受损后红色文字闪烁（0.5s 间隔）
- **发光文字**：text-shadow: 0 0 5px currentColor
- **边框呼吸**：Canvas box-shadow 使用当前状态色，失败时切换为红色

## 故障艺术风格指南

- 所有 UI 文字具有轻微"像素感"，优先使用等宽字体
- 绿色文字模拟老旧 CRT 终端
- 橙色用于警告和 AI 相关元素，与绿色形成对比
- 半透明背景叠加，营造"全息投影"悬浮感
- 系统日志文本前面自动添加 `[系统]` 前缀
